Проектная работа по курсу **«Современные методы DevOps»** (ЮУрГУ, ВШЭКН).
Проект: **ТЗ 1. Система обнаружения ржавчины и коррозии** — автоматический контроль цилиндров на линии ПАО «ЧКПЗ».

## Задача

Находить на боковой поверхности и кромках цилиндра ржавчину, измерять её площадь, отличать лёгкую ржавчину от глубокой коррозии и выдавать вердикт `НОРМА` / `ВНИМАНИЕ` / `БРАК` / `ОШИБКА СИСТЕМЫ` в ПЛК линии.

- Лёгкая ржавчина ≤ 20 мм² → «Внимание».
- Глубокая коррозия или площадь > 20 мм² → «Брак».
- Обнаружение пятен от 5 мм ≥ 98%, погрешность площади ≤ ±15%, точность степени ≥ 95%.

## Стек

- **ML / CV:** Python 3.11, PyTorch, Ultralytics (YOLO-seg), OpenCV, NumPy
- **Backend:** FastAPI, PostgreSQL (архив 30 дней), выгрузка CSV
- **Frontend:** React (интерфейс оператора: снимок с масками, вердикт, площадь)
- **Инфраструктура:** Docker, Docker Compose, GitHub Actions (CI)
- **Железо для разработки:** AMD Ryzen 7 5800H, 16 ГБ RAM, NVIDIA RTX 3060 Laptop 6 ГБ
